# PLAN 01-01 — Top-down Match Lab v0.2

**Goal:** A LÖVE2D five-a-side offline football match in which only blue #10 is human-controlled.  
**Purpose:** Validate top-down tactical player movement before an individual career.  
**Output:** Playable match, physics, initial AI, Etrusco ball texture, tests, documentation.

## Context
Based on the former single-player Physics Lab in `main.lua`, the user-provided tactical reference screenshot and the Etrusco Unico image. User approved implementation.

## Acceptance criteria

- **AC-1:** Given a match, when it starts, then 10 discs are present (5 per team including goalkeepers).
- **AC-2:** Given any transition or goal, when play resumes, then human input remains assigned to the same blue #10 disc.
- **AC-3:** Given a ball crossing a goal line within the mouth, then the opposing scoreboard updates and kickoff restarts.
- **AC-4:** Given the same world state and inputs, when fixed-tick steps run without rendering, then results remain deterministic.
- **AC-5:** Given the reference asset is loaded in LÖVE, then the ball shows its Etrusco Unico artwork and maintains its circular physical collision.
- **AC-6:** Given a team in possession, when #10 requests a pass and a viable line exists, then an AI teammate may choose to pass without being forced.
- **AC-7:** Given close-ball dribbling, when the human changes movement direction, then ball control remains possible without magnetism or excessive speed.

## Tasks (1–3 atomic changes)

### T1 — Physics and field
**Files:** `src/sim.lua`, `main.lua`, preserved legacy lab.
**Action:** Create world coordinates, 120 Hz physics, match states, scoring and fixed one-disc control.
**Verify:** Headless `lua tests/test_sim.lua`; manual running/dribbling.
**Done:** AC-1 through AC-4 proven; AC-7 manual UAT.

### T2 — Team AI
**Files:** `src/ai.lua`.
**Action:** Five roles per team, initial pressing, support, pass/shot choice, E pass request.
**Verify:** Manual 5v5 playtest with tactical overlay.
**Done:** AC-2 and AC-6 UAT.

### T3 — Render, ball and checks
**Files:** `src/view.lua`, `assets/etrusco_unico.png`, README, tests and CI.
**Action:** Top-down camera, scoreboard, controls, supplied ball image, regressions.
**Verify:** CI syntax + headless tests, then manual LÖVE.
**Done:** AC-5 and readable full-field layout in-game.

## Boundaries
**DO NOT CHANGE:** Multiplayer exclusion, one-disc-only human control, no magnetic possession, earlier Physics Lab comparison.  
**OUT OF SCOPE:** Career, 11v11, licensed teams, offside/fouls, advanced tactics and stadium 3D.
