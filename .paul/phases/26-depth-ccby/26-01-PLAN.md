# PAUL 26 — Black-screen depth fix and CC BY GLB adoption

**2026-11-20.** User supplied a black frame from the real Table Soccer 3D game, plus 5 GLB models, and explicitly requested real, repo-integrable assets rather than more approximations.
**Branch:** `fix/3d-depth-and-ccby-model-pipeline`.

## PLAN
1. **Root-cause and visible pixel gate**. In `renderer3d.lua`, `love.graphics.clear(..., 1, 0)` sets **cleardepth=0**. Under `setDepthMode('lequal',true)`, all ordinary fragments at depth >0 fail and the background remains blank. Set depth clear to **1** and add a unit regression verifying argument position and a native LÖVE GPU smoke that reads back real canvas color and fails for a blank scene. Synthetic fixture for smoke must fill an appreciable area of the screen (previously 11 tiny triangles that did not check pixels).
2. **GLB review and source rights**. Compared uploaded files via their actual binary GLB JSON data, material/node hierarchy and licenses. `foosball_table (2).glb`, 3.34 MB, from **3D Content Online** (https://sketchfab.com/3d-models/foosball-table-5f70863c2cf74e99ad084a493209dbac), `CC-BY-4.0`, has 103 distinct mesh primitives and all eight rod groups distinguishable geometrically, 73,636 triangles, 8 materials. Other `foosball_table (1).glb` has 2 mesh objects and `(3).glb` one merged mesh, both CC BY 4.0. Two `marble_foosball` are CC BY-NC 4.0 (not suitable for commercial release as-is).
3. **Repository-ready asset path.** Add reproducible importer for directly uploaded `foosball_table (2).glb` into `local_assets/3d` 11 native GPU streams by grouping meshes spatially into 8 independently moving rods and static table/field; preserve material colors; do not depend on old unredistributable VERTX3D OBJ. Include explicit credit/license and an opt-in path to commit the actual BY-licensed GLB directly as `assets/models/foosball_table.glb`. GitHub connector's text-only write path may prevent binary upload; if so, never claim the binary has been committed; supply a ready-to-commit file and clear instructions.
4. **Verification and Game Design Lab**: full Lua 5.4/LuaJIT + frozen NEON 11 regression; native Mesa/Xvfb LÖVE test checks **non-black pixels**. Actual user's Windows and full GLB visual UAT remains separate.
