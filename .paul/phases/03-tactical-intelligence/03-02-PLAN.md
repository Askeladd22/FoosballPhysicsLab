# PLAN 03-02 — Role choice: playable goalkeeper

**Goal:** permit the user to play blue #1 goalkeeper while preserving the game's one-disc-only control philosophy.

## T1 — Role selection
**Action:** Select GK or RM before a new match, no switching in the active match; preserve current role on R and use TAB to restart with a new choice.
**Verify:** Select via actual LÖVE callbacks and assert selected model number.

## T2 — Goalkeeper gameplay
**Action:** Apply existing WASD, physical collisions, Space clearance to blue goalkeeper; all other blue discs AI-controlled.
**Verify:** Headless movement, same kick impulse and no overwriting user GK steering by AI.

## T3 — User interface and regressions
**Action:** Add legible prematch choice, dynamic HUD role/number, mocked view and keyboard callback tests.
**Verify:** Lua CI + manual LÖVE graphics/game feel test.

## Acceptance criteria
- **GK-1:** Given the prematch role screen, When user presses 1, Then control is blue GK #1 for the whole match.
- **GK-2:** Given the prematch role screen, When user presses 2, Then control is blue midfielder #10 for the whole match.
- **GK-3:** Given GK play, When pressing WASD or Space near ball, Then GK moves and clears under same physical rules as other discs.
- **GK-4:** Given a GK match, When restarting with R, Then the controlled role does not change; TAB opens a fresh match role choice, never a live player swap.
- **GK-5:** Given existing headless match regressions, When role choice is introduced, Then scoring, goal restart, team size and deterministic simulation remain valid.

## Boundaries
No new role ratings, goalkeeper-specific superpowers, live switching, physics rewriting, online play or career management.
