# PAUL 15-01 — Foosball Mouse Rod Lab

**SEED type:** Game prototype / interaction validation (tight scope). **Status:** PLAN approved by user's direct request to experiment; APPLY in an independent branch. No merge or changes to the existing NEON 11 mode.

## Design decision ledger (SEED + Game Design Lab)
- **DECIDED:** LÖVE2D, offline single-player and mouse-driven mechanical rods.
- **DECIDED:** Vertical mouse delta translates the selected rod; horizontal delta sets its rotational target (left winds up, right strikes). No separate shot key.
- **DECIDED:** Four manually selectable rods (1–4), four basic AI rods, no tactical football roles. Include immediate training serve near the human forward rod.
- **ASSUMED:** An angular spring, velocity-dependent foot impulse, simple circles and a fixed timestep can reveal whether the gesture has expressive skill.
- **OPEN:** Control sensitivity, realism, accessibility, mouse acceleration and playtime fun must be tested by a human; automated tests do not establish these.
- **EXCLUDED:** Online, career, leagues, licensing, full ITSF tournament rule enforcement, sophisticated AI, ball spin/bank-spin.

## WHAT/HOW/WHERE (Game Design Lab)
WHAT: selected rod translation, rod angle and angular velocity, ball position/velocity, collision outcome.
HOW: up/down motion repositions all figures; horizontal swipe rotates them with inertia; angular foot speed generates physical shots.
WHERE: no action buttons—player skill is reading ball position and timing a deliberate hand gesture.

## PLAN and acceptance criteria
1. **AC-1 Input orthogonality:** dy changes only selected rod translation target; dx only angle target. Selection by 1–4/wheel changes controlled rod; other human rods remain static until selected.
2. **AC-2 Mechanical interaction:** rods translate/rotate under finite velocities; a positive swing near ball produces a repeatable physical impulse instead of a scripted kick.
3. **AC-3 Rules:** upper/lower and closed sidewalls bounce; the open goal scores; 5 goals ends match; restart/replay deterministic.
4. **AC-4 Human readiness:** independent \`experiments/foosball\` LÖVE game with visible selected rod, full rod assembly, legible HUD, recenter/capture controls.
5. **AC-5 Verification:** headless tests Lua5.4/LuaJIT and static syntax run in CI; human UAT remains **NOT_RUN** until a user tests the mouse feel.

## UAT — falsifiable test, not a claim
In 5 minutes, can a new player line up a rod and intentionally score using just mouse axes? Observe attempts before first purposeful shot, rod overcorrection, cursor-edge problems, accidental kicks and clarity of figure contact. Compare captured/unlocked mouse and 3 sensitivity settings. Revise control mapping if players mostly rotate when trying to translate or cannot reproduce shots. No pivot decision until observed gameplay.
