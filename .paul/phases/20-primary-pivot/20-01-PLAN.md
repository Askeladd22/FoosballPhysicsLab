# PAUL Phase 20 — Foosball becomes the repository's primary application

**Baseline:** `71b8c0bde5a89e70888c6bc0738f49e6e8e8524c`.
**Branch:** `feature/foosball-primary-project-pivot`.
**User intent:** update the project to reflect the foosball pivot, preserve the 11vs11 code and tests, and assess uploaded real-world 3D/CAD models for practical use.
**Game Design Lab mode:** evidence update + narrow scope gate (no extra game features).

## PLAN
1. **Make the product truthful:** `love .` launches Foosball Lab, with an explicitly supported `--legacy` flag to run the frozen NEON 11. Preserve original root 11vs11 controller *verbatim* under `legacy/neon11/main.lua`; do not move `src/` or edit its game logic.
2. **Preserve regressions:** existing headless tests continue to exercise 11vs11; a new boot-smoke test checks native default vs opt-in legacy and mocked historical test routing. Run Foosball tests first in CI, but retain legacy tests.
3. **Reset project-facing documents:** concise foosball-first README and `PLANNING.md`; archive old full README/SEED/PAUL status under `legacy/neon11/`; update top-level `.paul/STATE.md` and add a history note. Do not rename or delete the repository.
4. **Audit uploaded assets:** GLB: 10,863,860 bytes; glTF v2, one mesh/one primitive, 19,936 vertices, 22,855 triangles, 3 embedded 2048² textures, 0 animations/skins. Author/license/source declared in embedded asset extras: owestgate / CC BY 4.0 / Sketchfab page. STEP: CATIA V5 AP203 export from 2013-04-02, 41 PRODUCT records, 199 solids, 4,965 CAD faces, 1,885,176 bytes, no rights statement in file. Document suitability and a non-destructive local import workflow.
5. **Don't silently convert the physics to 3D:** first use GLB for static-table mood/reference or offline pre-render, STEP for rods/feet/mechanical dimensions *only when rights permit*. Full LÖVE 3D requires segmentation, camera scaling, pivot rigs, UV/material conversion, render benchmark, and comparison against the current fixed-step 2D collider. Keep player physics 2D until a validated vertical slice.

## Game Design Lab stop rule
Do not start a graphics-engine migration simply because the user has models. First benchmark whether a static cropped/isometric table background makes ball, selected rod and striking face more legible than Neon Glass 2D, then decide on rigging only if useful.
